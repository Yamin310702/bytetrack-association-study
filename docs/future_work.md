# 향후 연구 계획

**아직 구현·평가하지 않은 계획**입니다.

가설: 저신뢰도 2차 연관에 움직임 일관성 검사를 추가하면, 오탐지를 줄이면서 IDF1과 HOTA를 대부분 유지할 수 있다.

기존 Full ByteTrack과 motion gating을 추가한 버전을 같은 검출 캐시에서 비교합니다. 원 코드에 이미 있는 칼만 예측과 gating helper를 활용하는 기존 기법의 적용 연구이며, 새 알고리즘을 발명했다고 주장하지 않습니다.

예비 기준은 FP 감소와 IDF1/HOTA 각각0.2 percentage points 이내의 감소 허용입니다. 이 값은 연구자가 정할 허용 폭이며 통계적 유의성 기준이 아닙니다. FN 증가도 함께 확인하고 구체적인 허용 범위는 실행 전에 정해야 합니다.

이미 관찰한 일곱 장면에서 튜닝한 결과는 개발 결과로 표시합니다. 더 강한 일반화 주장은 튜닝에 사용하지 않은 추가 주석 영상과 체크포인트 훈련 데이터의 중복 확인이 필요합니다. 현재 ID 변경 사례가 motion gating으로 반드시 해결된다고 가정하지 않습니다.
